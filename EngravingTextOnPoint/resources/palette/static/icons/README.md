# Palette format icons (dummy)

Fusion Sketch Text–style stand-ins for the Format column. Prefer stock Fusion 16×16 PNGs when packaging.

| File | Control |
|------|---------|
| `flipH.svg` | Flip horizontal |
| `flipV.svg` | Flip vertical |
| `justifyLeft.svg` / `justifyCenter.svg` / `justifyRight.svg` | Horizontal justify |
| `alignTop.svg` / `alignMiddle.svg` / `alignBottom.svg` | Vertical align |

The dummy palette inlines equivalent SVG in `palette.js` so `currentColor` tracks theme. These files are the editable source / extract targets.
